SETUP GUIDE

1. Create a free EmailJS account:
https://www.emailjs.com/

2. Create:
- Email Service
- Email Template

3. Replace these values in index.html:

YOUR_PUBLIC_KEY
YOUR_SERVICE_ID
YOUR_TEMPLATE_ID

4. Put your video file in the same folder.

Rename it to:
your-video.mp4

OR edit this line in index.html:

<source src="your-video.mp4" type="video/mp4">

5. Open index.html in browser or host online.

IMPORTANT:
The visitor must allow location permission.
